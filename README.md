# Tienda Online

Esta página web es un proyecto de e-commerce básico creado en HTML, CSS y JavaScript.  

## Secciones principales:
- **Inicio:** Presentación de la tienda y bienvenida.
- **Productos:** Lista de productos destacados con botón de compra.
- **Reseñas:** Comentarios de clientes satisfechos.
- **Contacto:** Formulario para que los clientes puedan enviar mensajes.

El propósito de esta página es servir como ejemplo de un sitio de ventas en línea sencillo y funcional, que puede expandirse con más productos y funcionalidades en el futuro.
